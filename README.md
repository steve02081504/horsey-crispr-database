# Horsey CRISPR Database

A DNA sample browser and manager for [Horsey Game](https://horseygame.com) players: browse, search, and organise in-game CRISPR / DNA configurations in one place, with multi-language UI and local database import/export.

This is a fan-made companion tool and is not affiliated with Captain Games.
